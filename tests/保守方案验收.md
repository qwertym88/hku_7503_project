# 固定路线方案验收与证据

2026-11-11，状态：**计划，尚未验收**。由M5主持，M3独立量测，模块主责执行。先读[任务安排](../docs/给队友看/分工与任务拆解.md)与[任务流程](../docs/给队友看/任务流程说明.md)。本表验证真实雷达建图、地图实时定位与固定路线取放；不证明已满足仍未实现的扫码启动/货架扫码或在线规划。定位不设统一厘米级精度门槛，取放实际成功仍须机械与净空验收。

## 每次测试先记录

运行ID、日期、执行人/见证人、代码提交、固件版本、配置文件/版本、地图文件/版本、AMCL初始化、场地和地面、货架/载荷、顺序、启用传感器、起点摆车、供电状态、操作命令、预期标准、实测值、通过/失败、证据位置。操作命令由负责人实现后补齐；空字段不能记为通过。

小体积表格、摘要和截图进Git；bag/大视频放共享存储，证据列写可访问位置、文件名、时间段、必要时校验值。不要只指向被.gitignore忽略的本机tests/logs/。文件不存在或链接打不开即缺证据。

## 必测故障

| 输入/条件 | 应有结果 |
|---|---|
| 无首条局部反馈、原始/滤波odom过期、scan/必要IMU断流或定位TF不可用 | 不起步/停车并FAILED；不能把旧值当正常输入；AMCL正常运动触发更新不能误当断流，不设厘米精度启动条件 |
| 编码器无进展、横偏/角偏超限、动作超时 | 当前段失败、零速；不执行下一状态或举升 |
| 前进/后退路径有障碍、转弯扫掠有障碍 | 按实测外形检查并停车；包含载货/近货架遮挡场景 |
| kill上位机、拔USB、速度断流 | 固件在0.5s内停车。发生 Agent 失联时，重连后恢复遥测，动作保持锁定，显式解锁后才接受新指令 |
| 物理急停与释放、节点/板重启 | 急停有效；释放后保持待命；载荷支撑按机械实测记录 |
| 运行时取消、等待升降时达到180s | 当周期检查截止，零速并锁存；保持支撑，不盲目放下；停止延迟记录 |
| 缺段/空参数/无效顺序/混跑速度发布者 | 拒绝启动；证明缺失配置没有被当零值执行 |
