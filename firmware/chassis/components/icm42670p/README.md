# 板载ICM42670P驱动来源与改动

来源：本机`~/Desktop/Samples.zip`，Yahboom官方`esp32_samples/read_imu/components/{icm42670p,i2c_master,inv_imu}`。逐文件原始SHA256及是否修改见`official_sources.json`。`inv_imu`原样保留，含其InvenSense版权和许可文字，不能将整个目录误标为本项目其他组件的Apache许可。

保留官方器件身份检查、自检、±4g/±2000dps量程、400Hz ODR、FIFO读取及FSR获取；封装调整如下：

- 用core0独立任务5ms轮询FIFO，替换GPIO41中断触发，避免对中断服务的额外依赖。
- 启动按步骤检查错误；失败留存状态，不复位整板。I2C单次超时20ms，取消官方多次长重试；内存分配、I2C初始化返回错误。
- 仅在FIFO事件同时标记加速度/陀螺有效时转换并保存样本，INT16_MIN无效值拒绝；读取失败立即使缓存无效。
- 增加临界区保护的六轴快照、接收时间、序号与健康信息。ROS线程不直接读取多组不同步的全局数组。
- 官方_g/_dps getter实际已返回SI，本项目继续提供这些兼容接口，但新ROS路径只使用带明确单位的快照。加速度重力常数使用9.80665，量程分母沿用官方INT16_MAX。
- 不自动估计零偏，不变换安装坐标，不计算姿态。IMU故障不会伪造零值或继续刷新旧样本的时间戳。

`imu_sample.h`为本项目新增的SI转换及新鲜度判断，用于实际驱动和主机测试。其他引脚及轮距参数与本组件无关。
