# ESP32 micro-ROS 固件（M2）

实现 3 件事：

| 方向 | 接口 | 内容 |
|---|---|---|
| 订阅 | `/cmd_vel` (`Twist`) | 麦轮逆运动学 → 4 轮目标转速 → 编码器 PID |
| 发布 | `/odom` (`Odometry`) | 编码器推算位置 + yaw |
| 订阅 | `/lifter` (`UInt8`) | `1` 升起 / `0` 放下，带限位与堵转保护 |

## 必须做到
- **速度看门狗**：断流 0.5s 内停车。
- **上电双人复核**：电机线白接头→控制板、黑接头→电机，接反会烧板。
- 麦轮左右旋配对正确，否则平移方向相反。

## 引脚 / 轮序 / 参数
- PPR 13，减速比 1:20（来自需求材料）。
- 引脚表、轮序、串口波特率：**待 M2 填写后替换本段。**
