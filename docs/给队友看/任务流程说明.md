# 固定路线任务流程

基线v2.1，2026-11-11。真实建图与实时定位必做，架构见[建图定位与固定路线方案](建图定位与固定路线方案.md)。面向M4/M5；分工见[任务安排](分工与任务拆解.md)，参数输入见[标定表](固定路线标定表.md)，验收见[测试协议](../../tests/保守方案验收.md)。以下是待实现的执行设计，不代表现有mission已经可运行。

## 一轮如何执行

赛前真实建图并保存；执行时重载地图、启动实时定位。固定摆车、装载冻结参数并初始化定位后，人工启动一次，之后按固定顺序自动运行。默认A→B→C→D，实际顺序在全轮验证前冻结；起点、路线和场地布置须匹配配置版本。扫码位只是停靠地标，程序停稳等待，不依赖扫码结果。

```text
IDLE
 → PRECHECK（地图/定位已就绪、scan/局部反馈/TF可用、参数齐全、举升低位、摆车正确）
 → START（单调时钟开始180s计时）
 → A: TO_STOP → DWELL → ENTER → LIFT → CLEAR_RACK → TO_DROP → LOWER → EXIT
 → B: TO_STOP → DWELL → ENTER → LIFT → CLEAR_RACK → TO_DROP → LOWER → EXIT
 → C: TO_STOP → DWELL → ENTER → LIFT → CLEAR_RACK → TO_DROP → LOWER → EXIT
 → D: TO_STOP → DWELL → ENTER → LIFT → CLEAR_RACK → TO_DROP → LOWER → EXIT
 → DONE（零速、等待人工复位）
任一步失败、取消、急停或180s截止 → STOPPED（零速、保持载荷支撑、不自动续跑）
```

| 状态 | 成功条件 | 谁提供 |
|---|---|---|
| TO_STOP | 沿预写路段到达本架停靠位，实际停靠满足机械容差并停稳；不以AMCL厘米误差作统一门槛 | M4路段执行；M3测量；M1定容差 |
| DWELL | 零速固定等待；时长按实测停车稳定时间冻结，初值可用1s | M5 |
| ENTER | 沿停靠朝向前进+0.10m，反馈到达后零速；每架实测可覆盖默认值 | M4/M1 |
| LIFT | 零速发送/lifter=1，等待实测升起时间加余量；无到位传感器时只记录“等待完成” | M2/M5 |
| CLEAR_RACK | 按已测带载路段退离货架区再转向；若可直接离开，必须实测证明并显式配置为空序列 | M4/M1 |
| TO_DROP | 带载沿固定路线到本架专属放置位，禁止跨过已放货架 | M4 |
| LOWER | 零速发送/lifter=0，等待实测放下时间加余量 | M2/M5 |
| EXIT | 保持放置朝向后退-0.10m，确认托叉脱离；每架实测可覆盖默认值 | M4/M1 |

EXIT结束才进入下一架TO_STOP；末架EXIT结束立即停车。取货后CLEAR_RACK与放置后EXIT是两段不同动作，都必须记录。若0.10m不适合实物，修改该架参数、重新验收，不能假装默认动作已成功。

## 运动如何结束

直行按进入该路段时的位姿、朝向投影计算有符号距离；后退也有目标航向和横向误差限制。转向按归一化角差闭环，处理±π跨越。每段减速到位，输出零速并检查停稳后才执行升降或进入下一段。使用EKF局部里程计/odometry/filtered的距离和航向反馈，禁止仅用“速度×时间”判定完成；AMCL全局定位持续运行供观察、记录与健康检查，不直接改写短路段目标。

路线采用任务起点局部坐标：将当前/odometry/filtered出生位姿映射为任务(0,0,0)，无需重置EKF；场地测量坐标转换后写入配置并保留原表。AMCL初始位姿按已保存地图标定，与任务局部原点分开。进入/退出是车体系有符号增量；M4复用已验证EKF航向，M5不实现另一套融合。

## 超时和失败

所有动作有有限超时，等待也计入180s；使用单调时钟，停止检查独立于阻塞等待。每个运动段有最大距离、横偏、角偏限制，无进展/反馈过期则停车。必需的雷达/定位链路失效同样停车；定位精度普通波动记录，不增加厘米级门槛；低速接近检查必须区分货架与驶入通道，不能把载荷遮挡当作安全证明。

失败不自动跳过货架、不盲目重试0.10m、不从内存状态继续；人工确认载荷和姿态后重新摆车启动。时间到或故障时保持举升支撑；不自动在任意位置放货。电机看门狗与物理急停仍有效，机械如何在掉电后托住货架由M1验证。

## 运行记录

M5记录运行ID、代码提交、配置版本、顺序、起止时间、状态进入/退出、段号、目标/反馈、失败原因和建图/定位配置。记录地图、AMCL与TF真实运行状态；固定路线不具备动态绕障或失定位后自动恢复能力，记录与实际实现一致。
