# 运行说明

## 0. 需要什么

- Ubuntu 24.04 或树莓派 5，已安装 **ROS 2 Jazzy**。
- 依赖：`colcon`、`python3-yaml`、`python3-opencv`、`slam_toolbox`、`nav2`（或仅 `nav2_msgs`）。
- 实机另需：MS200 雷达驱动、camera_ros（需源码编译）、ESP32 固件已烧录。

## 1. 构建

```bash
cd ros2_ws
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install
source install/setup.bash
```

修改了 launch / 配置 / 消息后必须重新 build 并重新 source。

## 2. 统一启动

```bash
ros2 launch robot_bringup bringup.launch.py
```

`robot_bringup` 负责按顺序拉起：相机、雷达、micro-ROS agent、定位、导航、mission 状态机。
**当前各包为空壳**，等队友接入后再逐个填实。

## 3. 通信域

```bash
export ROS_DOMAIN_ID=42            # 实机
export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST   # 同机调试
```

模拟/离线测试用独立域（如 197），避免和实机互相干扰。

## 4. 分模块单独启动（推荐日常开发用）

不用等整车做好，各自启动自己的部分：

```bash
# 雷达
ros2 launch <lidar_pkg> lidar.launch.py

# 相机
python3 -m camera_ros.camera_node

# micro-ROS agent（Pi5 侧）
ros2 run micro_ros_agent micro_ros_agent serial --dev /dev/ttyUSB0

# 状态机（集成时）
ros2 run mission_control mission_node
```

## 5. 常用观察命令

```bash
ros2 topic list
ros2 topic echo /qr
ros2 topic echo /odom
ros2 topic echo /imu/data
ros2 topic hz /scan
ros2 topic pub /cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: 0.1}, angular: {z: 0.0}}'      # 手推一下底盘（小心！）

# 举升 / 放下
ros2 topic pub --once /lifter std_msgs/msg/UInt8 '{data: 1}'
ros2 topic pub --once /lifter std_msgs/msg/UInt8 '{data: 0}'
```

## 6. 手动兜底（B 档演示）

```bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

键盘遥控即可完成取-放，用于演示"手动控制"档位。

## 7. 建图与导航

```bash
# 建图（绕场一周）
ros2 launch slam_toolbox online_async_launch.py
ros2 run nav2_map_server map_saver_cli -f ../maps/field

# 导航（载入地图后）
ros2 launch nav2_bringup bringup_launch.py map:=../maps/field.yaml
```

**定位用 EKF + AMCL**：EKF 融合轮式里程计与 IMU（`robot_localization`），再把结果交给 AMCL 做地图匹配。
输入名按 linorobot2 惯例是 `odom/unfiltered` + `imu/data`——若我们的固件发的是 `/odom`，**用 remap 对接，不改固件**：

```bash
ros2 run topic_tools relay /odom odom/unfiltered
# 或在自己的 launch 里 remap，别去改固件
```

地图存到 `maps/`，参数存到 `ros2_ws/src/robot_bringup/config/`。

## 8. 测试与记录

```bash
# 记录一次运行，用于复盘
ros2 bag record /qr /odom /scan /cmd_vel /lifter
```

运行日志、bag 不进 Git（见 `.gitignore`）。

## 9. 常见问题

| 现象 | 排查 |
|---|---|
| 看不到话题 | 通信域不一致 / 忘了 source install |
| 车往反方向走 | 麦轮左右旋或电机线接反 |
| `/odom` 一直漂 | 编码器 PPR/减速比填错；检查麦轮打滑 |
| 相机无图 | camera_ros 未编译成功；换 V4L2 直连兜底 |
| 雷达没数据 | 串口设备名不对；加 udev 规则固定 |
| 舵机发热/不动 | 堵转保护未生效；立即断电检查机构是否卡死 |
