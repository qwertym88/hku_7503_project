## IMU 交接给 M4 的限制

`/imu/data` 为 best effort，`frame_id=imu_link`；角速度 rad/s，加速度 m/s²，包含重力。只发六轴测量，`orientation_covariance[0]=-1` 表示无姿态估计；角速度/加速度协方差全 0 表示未知。原始 `/odom` 不融合 IMU。

本次静态零偏标定已完成，板端执行XYZ原始角速度减 `[-0.0119512194,-0.0046553588,+0.0230571526] rad/s`。补偿后均值约 `[-0.00067810,-0.00033489,+0.00066753] rad/s`，Z由1.32108°/s降至0.03825°/s，若直接积分残余仍约2.29°/分钟。11月18日零偏仅保留为历史；本次完成的是单次前后静置验证，仍需多次重启/温度与受控旋转复测。未做加速度六面标定，单次静置不能区分倾斜与加速度偏置。

用户确认 X 朝前、Y 朝左；平放 Z 约 +9.82 是向上支撑比力，与正 Z 朝上相符，无需单独反转 Z。精确安装角度、三轴旋转正负仍未独立验收，URDF 中的安装外参不能据此直接盖章。

本次补偿后消息年龄均值5.95ms、范围3.02～10.51ms，无时间戳倒退。历史平放窗口均值93.8ms，另一手动姿态窗口曾约-116～253ms；本次未复现该现象，历史原因仍待查。诊断 `imu_age_ms` 约 2～4ms 仅表示 MCU 本地样本新鲜度，不等于主机端时间戳年龄。IMU 断流时停止发布旧数据，但当前固件**不会仅因 IMU 失效禁止速度命令**；M4/M5 的反馈失效停车仍需实现验证。

旧 `robot_navigation/config/ekf.yaml` 仍使用 `odom/unfiltered`，旧 launch 还存在将滤波输出改回 `/odom` 的接线。M4 应按[接口契约](模块接口说明.md)改为原始 `/odom` → EKF → `/odometry/filtered`，仅 EKF 发 `odom→base_footprint`；该接线和实车联合运行尚未完成。

操作者亲手执行的分阶段命令、预期现象与结果表见[M2手动测试步骤](M2手动测试步骤.md)。

## 接下来的执行顺序

1. **收尾IMU方向与重复性。** 静态零偏校准已完成，不再重复原始标定；按手动测试第4节独立核对三轴旋转符号，补一次断电重启/预热后只读采集，并复查约48Hz节拍与安装外参。
2. **新M4、四轮计数与低速闭环。** 架空手转M4，逐轮正反各3圈确认每圈约1040计数；再分别前进、后退、左转、右转，每次1秒，记录实际方向和反馈，不能只看静止计数。工具与命令见[手动测试第2、5节](M2手动测试步骤.md)。
3. **先验停车与急停，再落地。** 测停止发布速度、结束agent、拔USB的物理停车，从最后有效命令到实际停轮应≤0.5s并留视频。物理急停及释放/复位不自动续跑仍需补齐实现与验收；软件480ms不能代替物理结果。
4. **升降角度和载荷验收。** 位置控制已在校准采集中看到，当前目标0°/75°、等待各1200ms；支撑机构，验证实际上下端点、保持/撤销PWM、底盘互锁与供电，再完成真实载荷20循环。不把无升降命令的IMU采集算作升降验收。
5. **供电确认后落地标定。** 先确认每转计数，再标有效轮周长，最后标旋转系数；按[里程计标定](里程计标定.md)及本清单当前任务要求执行。空载、带载分别前后1m、0.10m、±90°/±180°各至少5次，目标1m≤3%、0.10m≤1cm、转角≤3°；不得仅用速度×时间证明精度。
6. **完成手动取放与M4/M5联合交付。** 记录空/带载各至少3分钟无掉电重启、手动取放一次；落实Pi固定设备名/agent启动与干净终端操作。将真实 `/odom` 和已补偿 `/imu/data` 接入EKF，验证唯一TF/速度发布者、必要反馈失效停车，再做整车C09～C16验收。

新 M4 反馈与四轮验收前，可推进 IMU、升降与部署。已提供 `tools/chassis_bench_test.py`，每次仅一个有限时长动作且要求明确确认架空；命令与保护复位见[固件说明](../../firmware/chassis/README.md)。整车精度和载荷结果保持待测。

## 每次实测记录什么

按[验收协议](../../tests/保守方案验收.md)记录运行 ID、执行/观察者、代码提交、应用 SHA256、几何/PID/校准参数、电池/地面/载荷、操作与证据位置。逐次填写下表，另存 `tests/firmware/日期_测试名.md`；原始小数据入库，大视频/bag 写共享位置与时间段。

| 运行 ID / 次数 | 固件哈希 / 参数 | 载荷 / 电池状态 | 动作 / 目标 | 外部实测 | odom 或诊断结果 | 误差 / 停车时延 | 结论 / 证据 |
|---|---|---|---|---|---|---|---|
| 待测 | | | | | | | |

计数是每轮累计编码器读数，`target` 是每 10ms 目标计数，`speed` 是 m/s，`pid_output` 是 PID 数值，不能视作 PWM 百分比或实测引脚电压。480ms 是软件超时设置，≤0.5s 是待验证的物理结果；标定/安全不能只靠命令值或软件状态判定。
