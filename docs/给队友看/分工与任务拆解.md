# 分工与任务拆解（5 人版）

> 目标：**保底跑通 A 档自动流程**（起点扫码自启 → 自动取 1 个货架 → 举升 → 送到目的区 → 不撞墙，3 分钟内完成）。
> 原则：**少做、复用现成组件、接口只留 6 个。**
> 编制：2026-10-22　｜　提交：2026-11-26（周四 17:00 实物 / 23:59 Moodle）

---

## 0. 团队与角色总览

| 编号 | 角色 | 一句话职责 | 主交付物 | 备份人 |
|---|---|---|---|---|
| **M1** | 机械 | 让车装得上、举得起、尺寸不超 | 实体车 + 举升机构 + CAD pack-and-go | M2 |
| **M2** | 硬件/嵌入式 | 让车能供电、能按指令动、能报里程 | ESP32 micro-ROS 固件 + 线束 | M1 |
| **M3** | 感知 | 让车"看得见"二维码 | camera_ros + `/qr` 解码节点 | M4 |
| **M4** | 导航 | 让车"知道自己在哪、能到点" | 地图 + 定位 + 点到点导航 | M3 |
| **M5** | 集成/PM/测试 | 把上面四块串成一条自动流程 | mission 状态机 + 测试记录 + PPT | 全员 |

**分工原则**：一人一主一副，**任何模块不能只有一个人懂**。M5 不写算法，只做调度、联调、验收。

## 3. M2 —— 硬件 / 嵌入式

**总交付**：ESP32 micro-ROS 固件（收 `/cmd_vel` 出 `/odom`，收 `/lifter` 动舵机）+ 可靠的线束与供电。

| 任务 | 周次 | 交付物 | 验收标准 | 依赖 |
|---|---|---|---|---|
| M2-1 供电拓扑 + 功耗预算 | W1 | 电气简图 + 保险/急停方案 | 各器件电压/电流匹配，留 2× 余量 | 器件清单 |
| M2-2 线束制作 + 接头复核表 | W1–W2 | 线束 + 上电前双人复核表 | **电机白→板 / 黑→电机，无接反** | M1 布局 |
| M2-3 micro-ROS 环境 + agent 联通 | W1 | 能 `ros2 topic list` 看到板子 | Pi5 与 ESP32 串口稳定通信 | — |
| M2-4 电机开环测试 | W2 | 4 轮正反转 + 方向正确 | 前进/右移/自转方向与预期一致 | M2-2 |
| **M2-0 拿到官方例程源码** | **W1 第 1 天** | Yahboom `microros_samples` | 确认 `twist_subscriber` / `odom_publisher` 能编译烧录 | 资料包/老师 |
| M2-5 **[移植官方例程]** 速度闭环（**不自己推逆运动学**） | W2–W3 | 速度闭环固件 | 给 `/cmd_vel`，实测轮速误差 < 10% | M2-0 / M2-4 |
| M2-6 里程计 `/odom` | W3 | 发布 odom（含 yaw） | 直行 1m 误差 < 3%，原地转 360° 误差 < 5° | M2-5 |
| M2-7 舵机举升 `/lifter` | W2–W3 | PWM + 限位/堵转保护 | 收到 1 升起、收到 0 放下，不烧舵机 | M1-3 |
| M2-8 `/cmd_vel` 订阅 + 看门狗 | W3 | 超时自动停车 | 断流 0.5s 内停车 | M2-5 |
| M2-9 手动兜底验证 | W4 | `teleop_twist_keyboard` 可用 | 键盘能遥控完成取-放（覆盖 B 档） | M2-8 |
| M2-10 固件冻结 + 烧录说明 | W5 | 固件源码 + 烧录步骤 | 队友能独立烧录 | 全部 |
| M2-11 **发布 `/imu/data`**（板载 ICM42670P） | W3 | `sensor_msgs/Imu` | EKF 能取到真实角速度（只需 z） | M2-3 |

**M2 不做**：自定义串口协议、电量上报话题、`/estop` 话题（用物理急停开关）、多板协同、**自己推导麦轮逆运动学**、**把固件框架从 ESP-IDF 换成 Arduino**（见决策 D6）。

> 📖 **动手前先读《[底盘参考实现](底盘参考实现.md)》**：**官方例程是四轮差速模型（普通轮、无横移，`V_y` 被忽略）**，可直接照搬做保底；**麦轮逆/正运动学只有 linorobot2 的 `kinematics` 库有**，要横移才需要它。
> 两条硬规矩：① **运动学只放在 ESP32 一侧**，Pi 侧不装麦轮控制器；② **保底阶段先不开横向平移**（`linear.y = 0`），把麦轮当四驱用，风险最低。

**M4 不做**：在线 SLAM 打比赛、自己写路径规划/控制器、自定义 Nav2 插件。

## 8. 每人都要遵守的交接规则

一个模块算"完成"，当且仅当：
1. 发布了契约里规定的接口（见《模块接口说明》）；
2. **在实机 / 集成机上跑过一次**，不是只在本机编译通过；
3. 提供了一行启动命令和一次成功记录（截图 / 日志 / bag）；
4. 在《单模块测试说明》对应章节里能被他人在不启动整车的情况下复现。

**没做到这 4 条的，不算交付，不要并入集成。**
