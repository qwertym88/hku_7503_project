路线、顺序、停靠点和四个放置位提前量好；保留真雷达扫描、slam_toolbox建图、地图保存/重载、EKF局部反馈及AMCL实时定位，复用已有实现。建图和执行分模式，不同时运行SLAM与AMCL。固定路段用连续局部反馈闭环，AMCL同步显示/记录全局位置；不追求厘米级定位，不要求在线规划或Nav2路径跟随。具体接线见[建图定位与固定路线方案](给队友看/建图定位与固定路线方案.md)，仍需实现新启动方式、状态机、执行器与实测参数。
