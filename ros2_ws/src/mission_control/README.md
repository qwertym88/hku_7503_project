# mission_control —— 任务状态机（M5）

## 职责
全流程调度中枢。**只做调度，不做算法**：不碰电机、不碰导航内部、不碰解码。

```text
等 /qr==START → 计时
 → 循环: 导航到货架 → 等 /qr==RACKx_xxxx → /lifter=1 → 导航到目的区 → /lifter=0
 → 全部送完 或 3 分钟到 → 停车
```

## 关键规则
- **每一步都有超时**，超时即跳过或回退，绝不原地卡死。
- 同一货架连续 2 次失败 → **跳过**，先保完成数量。
- 就近取货（货架坐标已知）。
- 发布 `/lifter`；订阅 `/qr`；通过导航包请求移动。
