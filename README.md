# DASE7503 固定路线物流机器人

当前执行基线v2.1：**2026-11-11明确保留真实雷达建图与实时定位，采用固定路线、固定顺序、预编程取放状态机**。固定摆车后人工启动一次，按冻结的A→B→C→D顺序搬运；路线和四个独立放置位提前测量。每架执行停靠等待→前进0.10m→举升→沿预写路线运送→放下→后退0.10m。

**雷达扫图建图、地图保存/重载和实时定位是必做功能。** 固定路线仍用编码器/IMU的连续局部反馈闭环；地图定位同步显示与记录，不以厘米级精度为前置门槛。在线规划、自动绕障与Nav2路径跟随为可选增强。QR不再决定任务启动或推进，保留既有截图；原任务书的扫码等评分口径由M5确认。

## 目录与开发

- `firmware/`：M2固件；`ros2_ws/src/robot_firmware_bridge/`：USB agent交接。
- `ros2_ws/src/robot_navigation/`：M4执行器；`mission_control/`：M5调度；`robot_bringup/`：统一启动。
- `ros2_ws/src/qr_perception/`、`tools/qr_*.py`：已完成QR能力留存。
- `docs/给队友看/`：当前团队指南；`tests/`：验收协议/记录/截图；`cad/`：机械交付。
- `maps/`：正式地图为执行模式依赖；`sim/`与在线规划方案保留，暂停新投入。

工作环境为Ubuntu24.04 + ROS2 Jazzy。工作区构建与真实启动状态见[运行说明](docs/给队友看/运行说明.md)。原始/odom只由M2发布，EKF输出/odometry/filtered及局部TF；自动执行时/cmd_vel只由M4执行器发布。
